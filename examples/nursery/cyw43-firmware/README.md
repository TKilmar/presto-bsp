# CYW43439 firmware (RM2 Wi-Fi module)

- `43439A0.bin`, `43439A0_clm.bin`: Wi-Fi firmware and regulatory (CLM) data, from
  [georgerobotics/cyw43-driver](https://github.com/georgerobotics/cyw43-driver/tree/main/firmware)
  via the embassy repository (`cyw43-firmware/`, synced 2023-08-21).
- `nvram_rp2040.bin`: board configuration for the Pico W layout, which the Pimoroni RM2 module
  also uses (embassy `cyw43-firmware/`).
